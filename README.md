# Debian 13 Repository

Repository konfigurasi APT Debian 13 (Trixie).

## Informasi
- OS: Debian GNU/Linux
- Version: 13
- Codename: Trixie
- Architecture: AMD64
- Repository: Official Debian

## Sources List

File sources.list berisi daftar alamat
repository untuk mengunduh dan memperbarui
paket Debian 13.

## Cara Penggunaan

1. Backup konfigurasi lama.
2. Salin file sources.list.
3. Ganti konfigurasi repository.
4. Jalankan perintah:

```bash
sudo apt update
sudo apt upgrade
```
